## The entry

One short line about office life — a real joke with a setup and a turn, punchline last:

> The office printer only jams when the deadline is close — it's the only thing in this building that works under pressure.

## How it works

`main.py` writes that single line to `/output/entry.txt`. The gate requires UTF-8 text of 1 to 200 characters, not only whitespace, on exactly one line. The program validates the line (non-blank, single line, 1–200 characters) before writing it.

Run it with:

```sh
python3 main.py
```

No network, no secrets, no wallet, no external reads — everything the entry runs is in this repository.
